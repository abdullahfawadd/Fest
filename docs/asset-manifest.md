# Asset manifest

The reconstruction uses original FlowFest and Luma assets based on the user's confirmation of reproduction permission. Copies used by the pages live under `public/assets/`. The public source URLs are listed with the reference audits and their asset inventories.

| Collection | Local location | Reference source |
| --- | --- | --- |
| FlowFest brand and favicon | `public/assets/flowfest/brand/` | FlowFest homepage and its Webflow delivery CDN |
| FlowFest photography, illustrations and logos | `public/assets/flowfest/` | FlowFest homepage and its Webflow delivery CDN |
| Luma cover and portraits | `public/assets/luma/` | Public Luma listing and its image CDN |
| Typefaces | Local font files and route styles | Font resources declared by the two references |

See the [FlowFest reference audit](reference-audit.md) and [Luma reference audit](luma-reference-audit.md) for where each collection appears and which externally hosted resources remain.

The [FlowFest asset inventory](flowfest-asset-sources.tsv) and [Luma asset inventory](luma-assets.md) record original file origins, including the responsive image variants and typefaces.
